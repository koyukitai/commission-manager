# Commission Manager

**Commission Manager v1.0**

クリエイター向けの依頼管理ツールです。

依頼・案件のスケジュール管理のほか、登録案件から自動で見積書と請求書を発行でき、入金状況の管理も簡単に行えます。

これら複数の依頼や取引情報などを、ひとつの画面から整理・管理することを目的としています。

## 主な機能

- **依頼者管理**：依頼者情報の登録・編集・管理
- **案件管理**：案件ごとの情報や進行状況の管理
- **見積書・請求書管理**：書類の作成、発行番号の付与、発行履歴の保存、改訂
- **入金・取引管理**：入金履歴、分割入金、未入金残高の確認
- **スケジュール管理**：打ち合わせや案件に関する納期、支払期限などの予定を管理
- **バックアップ・復元**：ZIP形式でのデータ保存と復元

## データの保存について

登録データは基本的に利用中のブラウザ内に保存されます。クラウドへの自動同期機能はありません。

- ブラウザや端末が異なる場合、データは自動的に引き継がれません。
- ブラウザのデータ削除などにより、登録内容が失われる可能性があります。
- 定期的なZIPバックアップを推奨します。
- バックアップファイルは暗号化されていないため、安全な場所に保管してください。

## 利用上の注意事項

- PDF形式の保存には、ブラウザの印刷機能を使用します。
- 税金・源泉徴収に関する計算機能は、税務上の正確性や法令適合性を保証するものではありません。
- 返金、過入金、入金の再割当など、一部の例外的な取引処理については現時点では検証が完了していません。今後、検証を進めてまいります。
- 重要な書類や取引内容は、利用者自身でも確認してください。
